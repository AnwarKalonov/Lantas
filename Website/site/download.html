The app is ad-hoc signed, not notarized. On first launch macOS may ask you to confirm; if it refuses, right-click the app, choose Open, then Open again. Builds are produced by CI on macos-latest, so the newest artifact is always on the Actions page.

Build from source

Node 20 and a Rust toolchain once, then the installer does the rest.

$git clone https://github.com/AnwarKalonov/Lantas.git
$open "Build Lantas.app.command"
