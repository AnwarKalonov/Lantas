Open it the first time

Mount the disk image, drag Lantas into Applications, then launch it from Applications or Spotlight.

  1. 01Mount

    Double-click the DMG. A Finder window opens with Lantas and Applications.

  2. 02Drag

    Drop Lantas onto Applications. Eject the disk image when the copy finishes.

  3. 03Open

    Launch it from Applications. The first open asks macOS for your approval once.

!
macOS says it “could not verify” Lantas

This build is ad-hoc signed, not notarized with a paid Apple Developer ID. Open System Settings → Privacy & Security, click Open Anyway next to the Lantas message, then open it again. The warning is expected and does not mean the download is damaged.

Do not disable Gatekeeper for the whole Mac. Full installation notes.

Prefer Terminal? Clear the quarantine flag
After dragging the app into Applications, run xattr -dr com.apple.quarantine /Applications/Lantas.app. This affects that copy only.

Then give it a model

Lantas opens without an account. Add a provider key in Settings, or point it at a local model. The Chrome extension is optional: it lets Lantas work in the Chrome window you already have open.

  • 01Providers

    Anthropic, OpenAI, Google, NVIDIA NIM, OpenRouter, Groq, Ollama or LM Studio.

  • 02A folder

    Choose a workspace for Code, or start in Chat and ask about anything.

  • 03Optional Chrome

    Load the extension once for the tab you are already signed into.
