Why Lantas exists

Every project I started ended the same way: a browser tab with the docs, a terminal with the error, an editor with the file, and me copying the same sentence between all three. The tools were fine. The gap between them was the whole problem.

Lantas is that gap closed. One window holds the chat, the workspace and a browser it can actually drive — with the same model, the same thread, and the same folder. When it clicks something, you see the cursor move first.

It is free, it takes any model, and it runs on a Mac that was already on the desk. No account, no subscription, no "upgrade to continue". If a tool is going to sit in my menu bar all day, it should not cost me an allowance.

Built nights and weekends between school, a chessboard, and a growing pile of half-finished ideas. The first version could only read a page. The one you can download now can type into a form, wait for the result, and tell you when it guessed wrong.
