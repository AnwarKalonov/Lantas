About me

I like chess, dark rooms, and rum raisin ice cream when I can find it. The rest of the time I am programming, starting companies I probably should not be starting at seventeen, and solving problems that annoy me enough to fix.

I get bored easily, so most things I build are the thing I wanted to use that afternoon and could not find.

Why Lantas exists

Every project ended the same way: docs in one tab, the error in a terminal, the file in an editor, and me copying the same sentence between all three. The tools were fine. The gap between them was the whole problem.

Lantas is that gap closed — chat, code and a browser it can actually drive, in one window, on one thread, with a cursor you can watch move. Free, any model, no account. If it is going to sit in my menu bar all day it should not cost me an allowance.
